Шрифты (необязательные; без файла берётся запасной):

ndot.otf или ndot.ttf   - Ndot-57/55 из github.com/xeji01/nothingfont (папка fonts/), заголовки в темах Nothing.

medeo_sans.ttf (.otf)   - Medeo Sans, пункт «Medeo Sans» в настройках шрифта.
google_sans.ttf (.otf)  - Google Sans; без файла берётся системный (на Pixel).
